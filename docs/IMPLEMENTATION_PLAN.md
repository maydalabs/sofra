# Phase 1 implementation plan

1. Scaffold strict Next.js, pnpm, Tailwind, shadcn/ui, localization, and quality tools.
2. Establish product constitution, decisions, architecture, domain, state-machine, and privacy documentation.
3. Add typed policy, pricing, lifecycle, authorization, public-projection, payment, notification, map, analytics, and monitoring boundaries.
4. Add normalized SQL migrations, public-safe views, generated types, and fictional seed data.
5. Build localized public discovery/detail and trust content.
6. Build demo-safe traveler, host, admin, partner, and booking foundations through domain services.
7. Add focused unit/component coverage and Playwright flows.
8. Run formatter, lint, types, tests, build, local startup, and responsive browser checks.
9. Commit local milestones. Do not push or deploy.

Phase 1 intentionally excludes real payments/payouts, production identity or phone verification, live chat, automated approvals, dynamic AI recommendations, and deployment.
